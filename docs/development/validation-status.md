## Not verified / known gaps

- **Windows and macOS:** not run locally. Code avoids platform assumptions and the CI matrix (`ubuntu`, `macos`, `windows` × Node 22/24) is configured, but no results exist yet. The symlink test is skipped on Windows.
- **Node 24:** not run locally (CI matrix only).
- **Live GitHub repository-scoped endpoints** (`/repos/{o}/{r}/…`: tree, contributors, releases, commit stats, details) were **blocked or returned 401/403 in this sandbox** (egress policy), so Level-3 inspection was exercised end-to-end only against mocked responses. README and manifest retrieval via `raw.githubusercontent.com` _was_ verified live. Run `repo-scout analyze owner/repo` with a token on a normal network to validate the rest.
- **Web provider** (`BRAVE_API_KEY`/`SEARXNG_URL`) and **Ollama embeddings**: fixture/fake-embedder tests only; no live validation.
- **Agent products:** configuration formats were checked against vendor docs (2026-11-11), but Repo Scout was **not** loaded inside Claude Code, Cursor, Codex, Windsurf or Gemini CLI themselves. Windsurf's documentation is mid-migration (see its guide).
- **npm publication:** not published. `npm view repo-scout` returned 404 (name unclaimed) on 2026-11-11; the name may be taken by publication time.
- **Relevance quality:** the evaluation set is synthetic; live component searches can return weak matches (e.g. a screen recorder for "audio capture"). Treat rankings as leads to verify.
- **Vulnerability coverage:** OSV is queried with the _minimum declared version_ of each dependency; lockfile-resolved versions are not parsed.
